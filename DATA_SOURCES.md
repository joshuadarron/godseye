# Data sources

Every external source godseye reads from, what it is used for, and where its
terms live.

This file records facts about the code and links the providers' terms. It does
not interpret those terms and it states no legal conclusion. Every row is
marked `needs review` until a human has read the linked terms and decided.

**The API stores and re-serves upstream data.** Ingestion workers write to
TimescaleDB (`flights`, `vessels`, `earthquakes`, `conflicts`,
`satellite_tles`) and the REST API serves that history back to any client, with
no authentication on read routes. That makes godseye a redistributor of ACLED
and OpenSky data, not only a consumer. Both rows need review with that in mind.

is bot filtering rather than a missing page. Open them in a browser.
